# 小艺 · 家庭群聊与记忆 Agent

Python FastAPI + SQLite + React/TypeScript 的本地单进程应用。家庭群保留 URL 身份演示；私人空间使用密码会话。小艺支持分层记忆、受控任务执行、周期与用药提醒、按主题订阅的主动关怀。

## Harness 与个人空间

点击“个人与提醒”，或打开 `/?user=dad&view=harness`。首次由本机管理员运行 `.venv\Scripts\python.exe -m backend.auth dad` 设置对应成员密码，再在界面登录；没有默认密码。真实家庭使用可在 `.env` 设置 `AUTH_REQUIRED=true`，让群聊与图片也要求密码会话。

已拆分会话理解、参与策略、记忆、上下文、任务编排、Skill、主动调度、触达反馈、身份同意、治理评测十个模块。新增个人/群组范围、工作/短期/长期记忆、冲突核对、目标规划与步骤审核、周期提醒、个人收件箱、免打扰、主题订阅、影子运行与事件触发。完整架构、接口和验收说明见 [docs/HARNESS.md](docs/HARNESS.md)。

新增关怀订阅默认仅观察；本人明确开启后才实际触达。私人渠道不会回退到家庭群；用药提醒不推断剂量和疗程，发送不表示已服药。

## 快速启动（Windows）

需要 Python **3.10+（推荐 3.12）**、Node.js **20.19+ 或 22+**、npm。

```powershell
git clone git@github.com:SJ-Ding/XYGroupChat.git
cd XYGroupChat
.\start.ps1
# 或双击 start.cmd
```

直接打开对应链接：

- 爸爸：http://localhost:8000/?user=dad
- 妈妈：http://localhost:8000/?user=mom
- 子女：http://localhost:8000/?user=child

没有 `user` 参数时默认进入子女身份，并将 URL 补为 `?user=child`。同一浏览器的不同标签页可使用不同身份；身份不保存在 Cookie 或本地存储中。群成员面板提供切换链接。非法身份会显示成员选择，不会静默切换。

脚本安装依赖、构建前端、初始化数据库并启动服务。首次安装需要联网。若 PowerShell 限制执行脚本，可直接使用 `start.cmd`。

模拟医院已作为项目内模块随主服务启动，地址为 `http://localhost:8000/hospital/`。在聊天中可直接说“打开模拟医院”或“帮我预约骨科上午的号”，小艺会通过 `hospital_simulator` 工具启动浏览器任务。预约会先停在核对页并发出确认卡片，只有当前用户点击“确认并继续”才会提交。实现与调试说明见 [hospital/README.md](hospital/README.md)。

需要演示聊天与记忆时运行 `start.ps1 -Demo`，或手动 `python -m backend.demo`（需使用项目虚拟环境）。演示记录均带有 **【演示】** 标记，不会触发后台记忆提取。默认不添加虚构的家庭事实。

局域网使用 `start.ps1 -Bind 0.0.0.0`，其他设备访问电脑的局域网 IP 和 8000 端口。手机与电脑需在同一网络。默认只监听本机；此版本不包含公网注册、HTTPS 网关或多进程部署。

## 模型配置

服务端启动时读取根目录 `.env`，模板见 `.env.example`。首次启动会复制模板，请在本地填写自己的 Key 后重启。`.env` 在 `.gitignore` 中，前端不会接收它，仓库不包含 API Key。

```dotenv
DEEPSEEK_API_KEY=在本地填写
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
DATA_DIR=data
```

变更模型配置后重启。界面中的 Agent 名称、系统提示词、自主介入开关、观察窗口即时保存到数据库。REST、图片和 WebSocket 请求都显式携带同一 `user` 参数。此演示模式的身份由 URL 自行选择，访问者可切换为任意家庭成员。

模型适配器采用官方 OpenAI 兼容 Chat Completions 格式，支持图片块、JSON 判断和工具调用。实际可用模型及额度取决于账号。模型失败不会阻止家人聊天；设置页显示失败原因并可重试。

## 使用流程

### 查看 Agent 运行状态

点击左侧（手机端底部）的 **Agent**，或直接打开 `http://localhost:8000/?user=child&view=agent`。此页面每 2 秒自动刷新，展示调度器心跳、模型配置状态、当前执行阶段、排队/失败/已完成任务、自主观察窗口与候选回复、决策日志、已加载 Skill、最近工具执行和待发送提醒。

调试聊天请打开 `http://localhost:8000/?user=agent`，或在群成员中切换为“Agent 聊天视角”。此页面沿用家庭群聊天布局，在成员消息下直接显示“需要回复 / 等待观察 / 无需回复”、意图分类、对象、置信度和判断依据；小艺的回复下可点击“查看上下文”，仅展示与这条回复关联的实际调用快照。Agent 聊天视角只读，不会以助手身份人工发送消息。开启 `AUTH_REQUIRED=true` 后，仍需已有家庭成员登录，访问范围沿用该成员权限。

新产生的分析、回复和候选调用会持久保存实际请求上下文、工具定义、公开模型返回、耗时与失败状态；图片仅保存占位标记，不记录图片字节、服务端密钥或模型内部推理。旧消息没有快照时会明确提示，无法事后重建当时的上下文。Agent 运行状态页继续展示任务、心跳等运行概览。

失败任务可在页面中重试，来源消息可跳回聊天查看；右上角仍可打开 Agent 设置。状态请求中断时会保留上次数据并提示，不会将旧数据误标为实时状态。模型密钥只显示“是否配置”，不做额外联网探测，也不返回密钥值。

1. 在三个标签页或设备分别打开 `?user=dad`、`?user=mom`、`?user=child`。
2. 群聊支持文字、最多四张图片、Enter 发送、Shift+Enter 换行、历史分页、断线补取和在线状态。
3. 输入 `@小艺 ` 后提问即可立即进入回复流程；附件和近期图片可用于看图。修改 Agent 名称后请使用新名称。
4. 普通消息在后台识别需求并静默提取有用的近期安排、状态和偏好。近期安排默认保留7天，临时状态最多1天；同一事项的更改、完成或取消会更新记忆，不会因此创建待办或提醒。稳定偏好也先短期保存，周期整理后才可能转为长期。
5. 对确定且适合助手帮助的未回应需求，先准备候选，**从最后一条相关消息起等待30秒后再核验发送条件**。普通聊天、引用、玩笑、家人间无需助手帮助的问答保持安静。相关回应取消候选，需求变更重新计时；发送前复核版本、时效、话题重复和冷却，支持仅观察模式。
6. 面向助手的明确请求不必先 @：例如“顾村公园下午开放吗”“三点一刻的时候提醒我出门”会直接回复。一次性提醒支持“十五分钟后”“今天下午三点一刻”“明天下午三点半”“15:15”等表达，按 Asia/Shanghai 和消息发送时间解析；未指定上午/下午的钟点优先取今天尚未到来的最近时刻，今天已过或未来日期缺少时段时先询问，不悄悄改到明天。请按提示补全整条提醒请求。也可要求 `@小艺 记住爸爸喜欢喝茶`、`@小艺 添加待办：爸爸周六买菜`。普通计划、引用和家人间交代不会因此自动创建提醒。
7. 家庭记忆侧栏支持检索、编辑、删除、修订记录及来源聊天定位。人工更正优先；删除后相同来源的自动提取会被抑制。

后台分析与生成需要模型网络请求；30秒是最早允许自主发送的时间，模型较慢时会继续等待。若较新消息分析失败，为避免发送过期候选，会暂停该群的自主跟进，直到重试成功。重启时恢复数据库中的任务并核验状态；运行服务才能触发定时提醒。

### 小艺的陪伴与记忆

小艺以陪伴型管家的方式回应，日常简短自然，先听懂情绪与需要；只在被叫到或确实能帮上忙时参与群聊。旧称呼 `@小忆` 仍可使用。升级会迁移默认名称与默认提示词，保留自定义提示词和其他自定义名称。

设置页可关闭自动短期记忆、调整默认保留天数（1–30天）和整理间隔（1–168小时，默认6小时）。新记忆会在5分钟内安排一次整理；此后按周期进行本地过期归档、完全相同条目的合并和稳定偏好的复核。三个不同日期、至少三条独立消息持续支持的稳定事实或偏好才会自动转为长期，仍标为未人工确认。暂定计划保留“考虑/尚未决定”，不会被升级为长期事实。

整理进度在 Agent 页“记忆整理”中查看。整理不会发送群聊总结，也不额外调用模型；自动提取仍随消息分析使用模型。人工更正优先，删除来源不会被旧消息重新提取；健康、药物和身份凭据不进入自动提取。个人记忆保持在本人空间。服务停止时不执行整理，重启后处理到期计划。

## 开发与测试

```powershell
# 后端（项目根目录）
.venv\Scripts\python.exe -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
# 前端开发，另开终端
cd frontend
npm ci
npm run dev
# 构建前端
npm run build
# 后端测试，项目根目录
.venv\Scripts\python.exe -m pytest -q
```

Vite 在 5173 端口代理 `/api` 与 `/ws` 至 8000；生产构建由 FastAPI 同源托管。API 文档为 `/docs`。

## 结构与数据

- `backend/db.py`：SQLAlchemy 模型、SQLite WAL、版本化初始化迁移、账号和家庭群种子。
- `backend/app.py`：URL 身份解析、群成员范围、图片、REST API 与 WebSocket。
- `backend/agent.py`：群级串行分析、候选预生成、持久任务与唯一发送键、历史摘要。
- `backend/memory.py`：中文单字/双字 FTS5 检索、人工更正、修订与来源抑制。
- `backend/memory_lifecycle.py`：即时短期记忆、同事项更新、周期整理与审计；`backend/persona.py`：小艺的身份与陪伴风格。
- `backend/skills.py`：可信 Skill 注册与执行协议；扩展说明见 `skills/family/SKILL.md`。
- `frontend/src`：响应式聊天界面、记忆、待办、设置与成员切换。
- `hospital`：虚构医院网页、预约数据与受限的 DOM 浏览器执行器。
- `tests`：隔离临时数据库及模拟模型；不消耗真实模型额度。

`data/family.db` 保存账号会话、群关系、消息、记忆和版本化应用记录，`data/uploads` 保存受群权限保护的图片。SQLite FTS5 是本地索引，无需 Redis、向量库或 Embedding 服务。迁移版本记录在 `schema_migrations`；后续表结构变更需增加显式迁移。备份请停止服务后复制整个 `data` 目录。

实际数据库与图片路径以 `.env` 的 `DATA_DIR` 为准。聊天记录、记忆数据库和上传图片均保留在本地，不随源码发布。

每条人类消息与分析任务同事务写入；消息先持久化再广播。客户端和 Agent 使用唯一键去重。群内生成配置按任务保存快照；设置修改会取消旧的待发候选。工具幂等结果与业务键共同处理重试。初版必须单进程运行，不要增加 `uvicorn --workers`。

验收与视觉对照记录见 [docs/QA.md](docs/QA.md)。最新 Harness 验证包含56项后端测试、12条离线策略样例和桌面/手机完整流程；早期真实 DeepSeek 记忆、看图与30秒自主跟进的实测保留在历史记录中。

家庭聊天、私人会话及其检索出的记忆会发送给配置的模型服务。任务规划只发送本次填写的目标与工具定义，不附带存储记忆。此版不提供消息撤回、任意脚本 Skill、语音视频、外部日历或系统推送；调度仍需服务保持运行。
