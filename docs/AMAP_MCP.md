# 高德 MCP

在本地 `.env` 配置 `AMAP_MCP_URL=https://mcp.amap.com/mcp?key=你的密钥`，重启后端生效。密钥不进入工具参数、模型上下文或版本库。

Agent 可调用 `amap_mcp`：先 `{"action":"list"}` 获取服务端工具及 JSON Schema，再 `{"action":"call","name":"maps_geo","arguments":{"address":"北京市天安门","city":"北京"}}`。支持地理编码、逆地理编码、地点搜索、路线、距离、IP 定位及天气等查询；以实际发现的白名单交集为准。前台和后台共用现有权限、超时和回执机制。

适配器实现 MCP 2025-03-26 Streamable HTTP 初始化、会话头、JSON/SSE 响应和目录分页。调用前按远端 Schema 校验，只发送当前查询必要参数；不传聊天记录和记忆。网络单次超时 6 秒，整体受工具执行器 10 秒预算约束；不自动重试。结果作为不可信资料，正文限制为 5500 字符并标记截断。当前为专用查询适配器，不支持安装任意 MCP 服务或执行远程写入工具。

验证包括 JSON/SSE 协议模拟、参数校验、未知能力过滤、错误脱敏，以及真实目录发现和公开地点地理编码。
