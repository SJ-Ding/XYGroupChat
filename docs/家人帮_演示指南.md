# 家人帮 · 演示指南（8 分钟）

> 一句话：**家里人哪儿不舒服，你只说一句，剩下的它办——挂号、付款、看完病后的吃药复诊，它都盯着。**

## 一、演示前准备（提前 10 分钟）

1. **配置**（项目根目录 `.env`）：
   ```dotenv
   DEEPSEEK_API_KEY=你的Key           # 不配也能演示：所有环节自动走规则兜底
   DEEPSEEK_VISION_MODEL=可识图模型    # 用于病历/药单照片；留空回退 DEEPSEEK_MODEL
   AMAP_MCP_URL=https://mcp.amap.com/mcp?key=你的高德Key   # 不配则用直线距离估算
   ```
2. **启动**：双击 `start.cmd`（或 `.\start.ps1`）。首次启动会自动写入演示家庭数据。
3. **开窗口**（建议双屏或左右分屏）：
   - 主屏：`http://localhost:8000/?user=child` —— 小林（女儿，照护人）视角，右侧是「家人帮」面板。
   - 副屏：`http://localhost:8000/?user=mom&elder=1` —— 妈妈的长辈大字视角（可在面板「多端视角」里一键打开）。
   - 浏览器代办时会**自动弹出一个 Chrome/Edge 窗口**，把它摆在评委看得到的位置。
4. 在面板「演示剧本」里点 **重置演示数据**，确认时钟显示“今天 20:10 · 第 0 天”。
5. 面板顶部状态条确认：`大模型 deepseek-xxx`（或“规则兜底”）、`高德地图 MCP`、`浏览器可视化代办`。

## 二、演示脚本

| # | 操作（演示剧本里点 ▶） | 画面 | 讲什么 |
|---|---|---|---|
| 1 | **妈妈说膝盖不舒服** | 妈妈在群里随口一句“今天阴天，膝盖又酸又胀…”（没有 @小艺）→ 小艺提醒小林，弹出「小艺建议」卡（病史 + 南京今天的天气） | **主动发现**：小艺在旁听，结合档案里的半月板旧伤和高德天气，判断是旧伤反应。只提醒照护人，不替家人做决定 |
| 2 | **小林一句话挂号**（或直接点建议卡上的「好的，帮挂号」） | “@小艺 帮我妈挂明天上午的号” → 号源对比卡：江苏省人民医院·张明远（上次的医生）、南京鼓楼医院（离家最近但上午约满）等方案 | **不说医院、不说科室也能办**：认人、补科室、补时段全靠家庭档案。排序是代码打分（距离 45%/熟悉度 30%/医生连续性 15%/职称 10%），理由和数据一致 |
| 2.1 | 在卡上点 ① 的「选这个」 | **旁边浏览器自动打开对应医院应用**，橙色高亮逐步点击：科室→日期→医生→号源→就诊人→核对页；聊天里同步显示进度 | 医院名称和地址来自高德，页面是明确标注的模拟站；浏览器停在核对页，**发确认卡等人确认** |
| 2.2 | 确认卡点「确认并继续」 | 浏览器提交 → 锁号成功 → 支付卡 | **模型没有提交和支付能力**；提交只由家人点击确认卡触发 |
| 2.3 | 支付卡点「去收银台支付」→ 收银台点「确认支付」 | 支付卡变“已支付”，凭证卡出现（可下载日历文件），就诊前 1 小时提醒已设置 | **端到端闭环**：一句话 → 选号 → 确认 → 锁号 → 支付 → 凭证。付款只能本人点 |
| 3 | **看病历/药单 → 守护计划** | 在群里发送病历或药单照片，小艺显示识图结果并生成守护计划卡；看不清的字段标“待核对”，点「确认计划」后生效 | **看完病它才刚开始**：视觉模型只抄写明确内容，不新增药、不改剂量；同一张图只识别、记忆一次 |
| 4 | **快进 7 天 · 爸爸用药周报** | 依从性卡：7 天打卡点、漏服周一/周三、今天还没打卡 → 点「提醒爸爸吃药」→ 在**爸爸的长辈窗口**点大按钮「已吃」 | **用药依从性**：照护人一眼看到问题并能一键提醒；老人端按钮大、能念给他听、也能直接说“药吃过了”。周报数字实时从 4/6 变成 5/7 |
| 5 | **快进到复诊前一天** | 复诊简报卡：康复第 14 天、用药 13/14、康复 12/14、3 条“建议问医生”、已找好上次张医生的号 | **记得病情、记得时间、把事办了**。点「确认挂号」会再走一遍浏览器锁号和支付 |
| 6 | **爸爸突发胸痛** | “胸口疼得厉害，有点喘不上气” → 急诊卡（拨打 120、原地休息、高德检索的就近综合医院）+ @小林 | **产品底线**：该劝去急诊时绝不挂门诊号。这一步**只走规则、不调大模型**，又快又确定 |

收尾：打开「家庭看板」（全家健康、近期安排、小艺记得的事）和「小艺在想什么」（每一步是规则、大模型、工具、Skill 还是记忆），讲技术链路。

## 三、对照课程要求怎么讲

| 课程要求 | 在哪里看到 |
|---|---|
| Skill 加载 | 思考轨迹里的“加载 Skill · family-appointment”；`skills/` 目录 10 个场景 Skill，按需 `skill_load` 渐进式加载；新增 `family-health-guard` |
| 工具调用 | `medical_profile`、`family_health`、`hospital_simulator`（浏览器）、高德 `amap_mcp`（距离/天气/周边）、`memory_search`、`web_query` 等，统一在 `backend/skills.py` 注册、校验参数和权限 |
| RAG 检索 | 家庭记忆分 general / medical 两个领域，FTS 中文检索 + 结构化医疗档案（`list_profile`），用检索到的档案补全挂号要素、生成简报 |
| 对话历史 | SQLite 持久化群聊，Agent 按话题组装上下文，超长时自动摘要 |
| 技术难点 | ① 浏览器自动化 + 人在回路（停在核对页、确认后提交、支付必须本人）② 规则保底 + 大模型增强的双通道编排 ③ 演示时钟统一时间线（快进后提醒、打卡、号源日期一致）④ 号源确定性生成 + 真实扣减 |
| 可解释 / 好代码 | 每一步写入思考轨迹；排序理由由数据模板生成；后端医院隔离、识图缓存、计划确认和完整挂号生命周期均有自动化测试 |

## 四、评委可能的追问

- **“模型乱下单怎么办？”** 模型没有提交和支付工具。提交只能由确认卡触发；支付只能本人在所属医院收银台点击。
- **“医院不开放接口呢？”** 正是用浏览器自动化的原因。选择器全部基于 `data-testid`，不依赖页面位置；查号走数据接口，锁号必须操作网页。
- **“没网 / 模型挂了怎么办？”** 所有用到模型的环节都有规则兜底，面板状态条会显示“规则兜底”；高德数据启动时预取，失败则用直线距离估算。
- **“老人不会用怎么办？”** 长辈大字模式：大按钮、常用语一键发、语音输入、“念给我听”。老人只需要点“已吃”。
- **“会不会乱诊断？”** 不诊断、不开药、不改剂量；急症只劝 120；每个页面标注演示数据与“不替代医生”。

## 五、现场兜底

- 浏览器没弹出：确认已安装 Chrome/Edge，或运行 `.venv\Scripts\python.exe -m playwright install chromium`；也可在 `.env` 设 `HOSPITAL_HEADLESS=1` 后台运行（流程不变，只是看不到窗口）。
- 想放慢浏览器：`.env` 里 `HOSPITAL_STEP_PAUSE=1500`（毫秒，低于 1500 时仍按 1500 执行）。
- 演到一半乱了：面板「重置演示数据」，3 秒回到第 0 天。
- 跳过挂号直接演后面：步骤 3 会自动生成一次已支付的预约（演示兜底），步骤 5 会自动确认守护计划。
