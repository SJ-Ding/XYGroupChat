# 家庭 Agent Harness

本次将原有消息分析、群记忆和提醒演进为同一服务中的十个模块。没有引入微服务、多 Agent 或外部推送。

## 模块边界

| 模块 | 实现入口 | 责任 |
|---|---|---|
| 会话理解 | `backend/intent.py`、`contracts.py` | 事件、意图、对象、话题、不确定性；分析结果本身不授予权限 |
| 参与策略 | `backend/participation.py` | 安静、回复、观察；相关性、版本、时效、话题去重和冷却 |
| 记忆 | `backend/memory.py` | 生命周期、可见范围、FTS、冲突、更正、修订和删除抑制 |
| 上下文 | `backend/context.py` | 完整条目预算、来源与否定条件保留、工具大结果引用；Agent 按话题选择历史 |
| 任务编排 | `backend/orchestration.py` | 有序步骤、状态、补充、授权、取消、恢复与局部重试 |
| Skill 与工具 | `backend/skills.py`、`authorization.py` | 可信过程说明、按需加载、精确动作授权、参数校验、幂等与超时 |
| 主动调度 | `backend/proactive.py` | 一次性/周期提醒、时区、订阅、事件候选、免打扰和配额 |
| 触达反馈 | `backend/proactive.py`、`harness_api.py` | 同事务消息出站记录、个人收件箱、送达与完成反馈 |
| 身份同意 | `backend/auth.py` | 密码、会话、失效、登录限速、个人命名空间及主题同意 |
| 治理评测 | `backend/governance.py`、`evaluate.py` | 无正文调用指标、决策反馈、离线样例与可选模型识别评测 |

`backend/agent.py` 连接这些模块，保留原有群级串行分析、持久任务、候选版本和唯一发送键。

## 使用入口与身份

点击导航“个人与提醒”，或打开 `/?user=dad&view=harness`。页面提供仅自己/家庭群范围，以及消息与反馈、分层记忆、执行任务、日常与用药提醒、关怀订阅、偏好与指标。

群内助手消息可反馈“帮到我了”“这次不用介入”“记忆有误”。对自主跟进反馈“不用介入”后，同一话题24小时内停止自主跟进，明确向助手求助仍正常响应；记忆纠错通过记忆编辑与冲突核对完成。

个人功能必须使用密码登录。首次由本机管理员设置对应成员密码：

```powershell
.venv\Scripts\python.exe -m backend.auth dad
.venv\Scripts\python.exe -m backend.auth mom
.venv\Scripts\python.exe -m backend.auth child
```

交互输入至少10位密码，没有默认密码，也没有远程首次抢注接口。改密码会使该成员旧会话失效。Cookie 为 HttpOnly、SameSite=Strict，HTTPS 下附加 Secure；数据库只保存会话 token 的摘要。失败登录按来源和成员限制为15分钟内5次。

默认保留 URL 群聊演示。设置 `.env` 的 `AUTH_REQUIRED=true` 并重启，可让原有群 REST、图片和 WebSocket 也要求密码会话。真实家庭使用应开启该选项。已登录时会话身份优先，不能通过 URL 切换成其他成员；同一浏览器各标签共享会话，切换成员需退出再登录，或使用独立浏览器上下文。

个人空间使用服务端确定的独立命名空间；客户端不能通过传入成员 ID 访问他人空间。记忆、消息、摘要、任务、工具结果、运行指标和提醒均跟随该边界。群接口不能访问个人命名空间，个人渠道不能回退到群。

## 记忆与上下文

- 生命周期：working 默认1天、short 默认7天、long 默认不失效；可设置明确有效期。
- 可见范围：group 群共同记忆、profile 群内成员画像、private 本人私人记忆。私人记忆不能保存进群命名空间。
- 过期、删除和无权限条目在进入模型上下文前排除。自动提取只处理高置信度的非敏感稳定事实，排除一次性安排和健康隐私。
- 自动提取发现冲突时生成待核对记录，不覆盖原事实；人工更正优先并结束对应冲突。删除采用墓碑、修订与来源抑制，阻止自动恢复；不物理清除历史修订或备份。
- 分析与生成分别控制文本预算，保持整条消息与来源，不截断否定条件。生成默认正文预算24000字符，工具循环另留20000字符上限；最多4轮、每轮6个调用。图片保持原有处理路径。
- 大工具结果保存在执行记录中；模型收到“缩小查询范围”的结构化提示，避免把截断数据当完整结果。

## 任务、授权与恢复

执行任务可手工录入步骤，也可在目标框填写需求并选择“让小忆规划步骤”。规划仅发送本次填写的目标、工具定义与当前时间，不附带聊天历史或存储记忆。模型只产生待审核步骤，不产生业务写入。

任务状态为 `waiting_input`、`waiting_authorization`、`queued`、`running`、`succeeded`、`failed`、`cancelled`。补充或修改未执行步骤会撤销旧授权；审核后一次授权精确绑定每一步工具及参数。失败重试跳过成功步骤；进程重启恢复运行中任务，使用稳定步骤运行 ID 和业务键去重。取消停止后续步骤，已经开始的单个动作可能完成，其真实结果仍会保存。

聊天分析任务另区分`reply_failed`：业务动作已完成，仅回复未送达。此时执行任务仍为成功，界面提供“仅重试回复”，不会重放成功的工具；回复使用当前真实业务状态。协议与恢复修复见[MODEL_FIX.md](MODEL_FIX.md)。

聊天中的以下明确命令由服务端生成窄授权并确定性执行，避免模型遗漏或扩大动作；私人会话不需要 `@`：

```text
@小忆 记住爸爸喜欢茶
@小忆 添加待办：准备晚餐
@小忆 完成待办：待办编号
@小忆 一分钟后提醒我们检查晚餐准备
```

自然语言中的复杂安排可先交流，再使用任务规划/表单确认。不能用模型输出的一个通用布尔值授予全部写权限。已加载的可信 Skill 过程说明随任务提供；未注册脚本不能执行。

## 提醒、订阅与反馈

- 明确约定的提醒独立于聊天分析和模型服务。支持一次性时间、按星期重复、IANA 时区、更改、暂停和取消。夏令时不存在的时间跳过，重复时间只触发一次。
- 免打扰默认对提醒和关怀生效；提醒可显式选择不受免打扰限制。恢复后按宽限期补发一次；超过宽限期记录 missed，周期规则跳到下一未来时间，不堆积补发。
- 生活、健康关怀按主题订阅，默认 shadow 仅观察；本人可以开启实际发送。默认每人每天一次、每群每天一次，约定提醒不占关怀配额。个人配额跨渠道，群配额可在 Agent 设置修改。
- 支持每日触发、待办24小时内到期，以及个人记忆24小时内到期事件。关联记忆与记忆到期事件仅支持本人个人空间；只发送核对提示，不发送记忆原文，删除或失效后不再用于日常关怀。
- 触达状态区分 sent、delivered、acknowledged、completed；另支持 snoozed、skipped、dismissed、stopped。仅写入收件箱不表示设备收到，界面由用户明确标为已读、确认或完成。无回复不会持续催促。
- 用药安排必须由本人明确输入；群内用药提醒需要单独分享同意。不推断药物、剂量或疗程，未确认不等于未服药。
- 可明确指定同群家人及等待确认时间。超时仅向该家人的个人收件箱发送一次“尚未收到确认”，不包含私人安排原文，也不推断事项未完成。改期、取消或已反馈后停止旧规则通知。

## API

以下管理接口均要求密码会话；`{scope}` 为 `personal` 或 `group`，群默认 `gid=1`，个人归属来自会话，忽略 URL 的 `user`：

| 接口 | 用途 |
|---|---|
| `GET /api/auth/status`、`POST /api/auth/login`、`POST /api/auth/logout` | 会话管理 |
| `GET /api/harness/{scope}/state` | 当前空间的记忆、冲突、本人任务、提醒、订阅、收件箱与指标 |
| `GET/POST /api/harness/{scope}/memories`、`PUT/DELETE .../memories/{key}`、`GET .../revisions` | 分层记忆与修订 |
| `POST/PUT/DELETE .../reminders[/{key}]` | 一次性与周期规则 |
| `POST/PUT/DELETE .../subscriptions[/{key}]` | 主题同意、影子/实际触达与退订 |
| `PUT /api/harness/personal/preferences` | 时区、免打扰和每日个人上限 |
| `POST .../deliveries/{key}/feedback` | 送达、确认、完成、稍后、跳过与停止 |
| `POST .../runs`、`POST .../runs/plan`、`POST .../runs/{key}/control` | 手工/模型规划、补充、授权、重试和取消 |
| `PUT .../tasks/{key}`、`POST .../reminders/{key}/control` | 待办完成与到期时间、提醒暂停和恢复 |
| `POST .../feedback` | 有帮助、过度介入、漏响应或记忆有误反馈 |
| `GET/POST /api/harness/personal/messages`、`POST .../jobs/{key}/retry` | 私人会话与失败恢复 |

原有群 API 保持兼容，群记忆查询新增有效期和可见范围过滤。数据库迁移版本2采用增量 payload，旧记忆默认群可见、长期；不会将旧群内容自动变成私人数据。

新建任务使用必填 `client_id` 去重，新建记忆和提醒支持同样字段，界面会自动携带。相同空间、成员、创建请求 ID 的重复提交返回原记录；修改内容使用 PUT，不复用创建请求 ID。

## 验证与运行边界

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m backend.evaluate
# 可选：对合成样例实际调用配置模型，消耗额度
.venv\Scripts\python.exe -m backend.evaluate --live
cd frontend
npm run build
```

离线12条样例覆盖闲聊、倾诉、玩笑、引用、家人间提问、用药话语、明确求助、不确定需求、可帮助事项与取消。默认评测检查标注意图经过参与策略后的结果；不能据此宣称真实模型识别准确率。`--live` 才检验模型识别。

上线先开 Agent 的“自主参与仅观察”，以及订阅的“仅观察”。核对决策记录后分别启用。治理页面展示调用延迟、失败、模型返回用量、参与动作和用户反馈；服务商未返回用量时标记未知，不计算虚构费用。

仍为本地单进程 SQLite 服务，需保持进程运行才能调度；没有操作系统推送或离线设备通知。私人会话与其检索结果仍会发送到配置的模型服务，使用前应确认该服务适合处理相应数据。
