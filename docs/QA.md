## 浏览器环境与流程

Browser 插件不可用，使用已安装的 Playwright 驱动 Microsoft Edge（Chromium），访问 `http://127.0.0.1:8000`。桌面 1536×1024，与概念图原生尺寸一致；手机 390×844。

流程：登录三个独立上下文 → 一人发送、其他人接收 → 刷新确认保留 → 新增并编辑记忆 → 创建并完成待办 → 上传图片并验证另一账号收到 → 手机布局与侧栏导航。

页面标题为“小忆 · 我们一家”，有真实聊天内容，无框架错误覆盖层，未发现 JavaScript 运行异常。未登录时 `/api/me` 返回预期的 HTTP 401，浏览器可能将此记作资源提示；这不影响登录流程。Python 测试有一条 Starlette 对 httpx 测试客户端的依赖弃用警告，不影响 17 项测试通过。
