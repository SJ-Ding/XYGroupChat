# 演示控制与支线

在家庭群右侧的「家人帮 → 演示剧本」中启用「演示控制」。默认关闭，只影响初始化的演示家庭（群 1）。退出演示控制或重置演示数据会清除模型、地图故障开关；重置演示仍沿用原有清空记录的行为。

- 支线按钮将普通成员消息写入现有消息队列，不赋予工具权限，也不保证请求必然成功。换时间、换医院、取消等操作仍受本地业务能力与授权约束。
- 模型故障覆盖该家庭的模型调用，识图故障时也不会使用缓存掩盖故障。通用聊天或预约决策可能报告失败；不承诺所有功能离线可用。
- 地图故障阻止就医编排请求高德；距离改为直线估算，不显示为实时地图数据。已有正常距离缓存保留，恢复故障后可继续使用。
- 号源被抢需要唯一一个正在填表的模拟浏览器任务，会实际占满选中模拟号源。退出控制不会释放占号，重置演示数据才清除。此操作不接触真实医院。
- 重复点击入口并发调用同一卡片，展示实际返回；是否只创建一次任务以执行链与任务记录为准。多人请求入口同样发送普通消息，沿用原有队列。
- 演示慢速为每步 3 秒，正常为每步 1.5 秒；关闭演示控制后恢复 HOSPITAL_STEP_PAUSE 配置。切换速度影响后续步骤。
- 浏览器步骤编号表示当前展示的动作，未表示该步骤已经产生业务结果。成功锁号仍以预约编号为准，支付仍由本人确认。
- 状态栏区分已配置、最近调用结果、故障注入、估算与距离缓存来源；已配置不代表服务健康。浏览器可视/后台是运行配置，具体任务结果在当前步骤区展示。

导演台主要用于桌面宽屏；沿用当前项目在窄屏隐藏侧栏的布局。
