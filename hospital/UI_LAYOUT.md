## 页面二：科室选择页（`DeptPage.tsx`）

### 流程进度条
| 属性 | 值 |
| --- | --- |
| 位置 | 顶部，`mb-6` |
| 内容 | 1.选择科室 → 2.选择医生号源 → 3.确认预约 |
| 样式 | `text-sm`，当前步蓝色高亮 |

### 布局 A：网格按钮（默认）
| 属性 | 值 |
| --- | --- |
| 结构 | 按 5 个分类分组（内科系统/外科系统/妇儿/五官科/其他） |
| 每组 | 独立 `med-card p-5`，含分类标题 |
| 网格 | `grid grid-cols-2 md:grid-cols-4 lg:grid-cols-6 gap-3` |
| 单卡片 | `p-4 rounded-xl border-2`，含 emoji`text-2xl` + 科室名`text-sm` + 描述`text-[10px]` |
| 科室数量 | 22 个，分散在 5 个分类卡片里 |

### 布局 B：搜索框 + 下拉（`?layout=search`）
| 属性 | 值 |
| --- | --- |
| 结构 | 单个 `med-card p-5` |
| 搜索框 | `input` 带搜索图标，`w-full py-2.5` |
| 下拉框 | `select w-full py-2.5`，22 个科室选项 |

### 医生与号源区（选中科室后显示）
| 属性 | 值 |
| --- | --- |
| 标题 | 科室 emoji + 名称 + 描述 |
| 布局 | `space-y-4`，医生卡片纵向排列 |
| 医生卡片 | `med-card p-5`，数量=该科室医生数（2-4 个） |

**单医生卡片结构**：
| 区块 | 尺寸 | 内容 |
| --- | --- | --- |
| 头像 | 56×56px `rounded-2xl bg-med-50` | emoji `text-3xl` |
| 右侧信息 | `flex-1` | 姓名`text-lg` + 职称标签`text-xs` + 简介`text-sm` |
| 擅长标签 | `flex-wrap gap-1` | 最多 4 个标签 `text-[10px]` |
| 号源区 | `border-t pt-3` | 标题「可预约号源」+ 号源按钮网格 |

**号源按钮**：
| 属性 | 值 |
| --- | --- |
| 布局 | `grid sm:grid-cols-2 lg:grid-cols-3 gap-2` |
| 单按钮 | `p-3 rounded-xl border`，左侧时段+时间+日期，右侧费用 |
| 时段标签 | `chip`，上午=琥珀色，下午=灰色 |
| 数量 | 每医生 2-5 个号源（含 10-30 和 10-31 两天） |

**科室页问题**：
- 科室选择和医生号源在**同一页**，选科室后医生列表直接在下方展开
- 真实医院通常是：科室页 → 独立医生列表页 → 独立号源页（或弹窗）
- 当前一页承载太多，滚动距离长

| --- | --- |

## 与真实医院挂号系统的差异（待评估）

| 维度 | 当前实现 | 真实医院（如京医通/微医/好大夫） | 差距 |
| --- | --- | --- | --- |
| **科室→医生→号源** | 同一页展开 | 通常分 2-3 个独立页面/步骤 | 一页承载过多 |
| **日期选择** | 写死 2 天 | 日历组件选日期，显示一周/两周 | 无日历组件 |
| **就诊人** | 写死 1 个 | 可选就诊人列表（本人/家人） | 无就诊人选择 |
| **科室分类** | 5 类分组展示 | 同左，基本一致 | ✅ 接近 |
| **医生信息** | 姓名+职称+简介+擅长 | 还含头像照片+排班+评价 | 缺头像/评价 |
| **号源展示** | 时段+时间+费用+剩余 | 还含号源类型（普通/专家/特需） | 缺号源类型 |
| **搜索** | 仅布局B有科室搜索 | 通常有科室搜索+医生搜索+症状搜索 | 缺医生/症状搜索 |
| **热门科室** | 展示全部 22 个 | 首页只展示 8-12 个热门，更多需展开 | 首页过多 |
| **支付** | 无（直接确认） | 选号后跳支付页，支持微信/支付宝 | 无支付环节 |
| **取消预约** | 无 | 记录页可取消 | 无取消功能 |
